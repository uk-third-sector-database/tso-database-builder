## Archive folder
 
Code in the archive/ folder is code used in initial data preparation, and in ccni webscraping.

These are not part of the main build work, but were used in the generation of the initial data, so are stored in this repo
for transparency and reproducability.
    


















`archive/visualise/` holds the old statistics-and-plots notebook (which
produced the table in the deprecated `release_info.tex`) and its optional
requirements file. It is not part of the release build. To run it:
`pip install -r archive/visualise/requirements-visualise.txt`.
