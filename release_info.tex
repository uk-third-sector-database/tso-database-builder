\section{Introduction  }

\textbf{Deprecated historical record.} This hand-maintained document is retained
for releases up to April 2025 only. From version 1.0 onward, the canonical
human-readable release notes are the changelog in the published Organisation
Register guidance. The archived release validation report and its SHA-256 hash
record are the canonical record of file names, row counts and hashes. Do not
update counts in this file independently.

The technical construction notes formerly described as \texttt{builder.pdf}
are now maintained in the Organisation Register guidance and
\texttt{RUNBOOK.md}.

\section{Alpha release 1: April 3 2025}

Fourth public release. 

This release included updated (January / February 2025) data from all ten sources. 

Historic organisational data collected for previous projects was omitted from this release. 
For Companies House organisations, this means that only data which can be found at Companies House using their API is now included.

In addition the following edits to the algorithm were made:
\begin{itemize}
    \item Improvement to the presentation of matches. In particular, matches from within the same source, such as charities which reregister, have the most recently 
active organisation present on the main spine. Previously the removal date was not being used to sort matches.
 \item  A flag 'is\_cic' has been added to the main spine, to indicate if an organisation is a community interest company. This is based on the company type field in the Companies House data.
\item More text encoding issues have been resolved, removing some non-ASCII characters from the data.

\end{itemize}

\section{Beta release 3: September 30 2024}

Third public release. Now includes data from Companies House bulk download released September 2024.
Bug fix to ensure dissolution dates are in the main spine except in the case where at least one of the 
matched organisations have not been removed from the relevant register. In all other cases a removed entity should
now have a removal date in the main spine. If there were competing dates (as in the case of a linked organisation), the most recent
date will be in the main spine, with alternatives in the supplementary table.
